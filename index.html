Angin Berhembus

Website unduh data historis dan ekspor ke Excel dengan mudah dari tiga sumber: Open-Meteo, Meteostat, dan NASA POWER.

Masuk dengan Token

Aplikasi ini memerlukan token akses untuk dapat digunakan. Hubungi admin Anda untuk mendapatkan token (durasi 1 hari / 7 hari / 30 hari).

2. Pilih Lokasi

    Belum ada kota yang dipilih.

    Pin tunggal: klik di peta untuk taruh marker. Marker bisa digeser. Area: gambar kotak - sistem otomatis membentuk grid 3x3 (kotak kecil < 1 derajat) atau 5x5 (lebih besar) lalu merata-ratakan data semua titik per hari.

    Belum ada lokasi yang dipilih di peta.

    2. Pilih Stasiun

    Belum ada stasiun yang dipilih.

    3. Periode Waktu

    Granularitas: per hari (daily). Semua kecepatan angin di seluruh data dan windrose menggunakan satuan m/s.

    Sumber: ERA5 reanalysis (1940 - ~5 hari yang lalu) untuk historis, dan model forecast untuk 16 hari ke depan. Sistem otomatis memilih.

    Sumber: observasi stasiun Meteostat (NOAA ISD/SYNOP), data harian. Maks 366 hari per request.

    Sumber: NASA POWER (MERRA-2 reanalysis + CERES/SYN1deg untuk radiasi), data harian. Tersedia 1981-01-01 sampai ~2 hari yang lalu. Maks 366 hari per request.

    4. Output Excel

    Mode bulanan membuat tabel bulan x tahun seperti laporan BMKG. Setiap variabel dibuat sebagai sheet terpisah di Excel.

    5. Variabel Cuaca

    Lima variabel harian yang diekspor (sama untuk semua sumber): suhu rata-rata (deg C), curah hujan / presipitasi (mm), kecepatan angin rata-rata (m/s), arah angin dominan (deg), dan lama penyinaran matahari (jam).

    Open-Meteo: data hourly diunduh lalu diagregasi ke harian di sisi klien - suhu & angin pakai rata-rata, presipitasi pakai total, arah angin pakai speed-weighted vector mean, penyinaran pakai total detik / 3600.

    Meteostat: kolom tavg, prcp, wspd, wdir, tsun (menit dikonversi ke jam).

    NASA POWER: T2M, PRECTOTCORR, WS10M, WD10M. NASA POWER tidak menyediakan kolom sunshine duration langsung - kolom “Lama penyinaran” diisi radiasi GHI all-sky (ALLSKY_SFC_SW_DWN, kWh/m2/hari) sebagai proxy energi penyinaran.
